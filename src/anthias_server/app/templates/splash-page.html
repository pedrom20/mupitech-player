{% comment %} Per-device identification chip (location / group / device name), e.g. "Biblioteca / Receção / Balcão 1" — useful when several devices are laid out side by side. Deliberately NOT server-rendered from Django template context: this page is baked into the image at build time and served identically to every device, so there's no per-player data available here. Instead it's read at runtime from a small JSON file the Fleet Manager writes directly onto the host (bind-mounted into the container, see docker-compose-player-*.yml) — a host file survives a container recreate (image update, Watchtower auto-update) since it isn't part of the container's own writable layer, unlike patching this page's HTML directly would be. Silently stays hidden if the file is missing (device not yet linked to a location/group) or unreachable. {% endcomment %}
